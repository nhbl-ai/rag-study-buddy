# Project context

- Product: RAG Study Buddy, a chat application that answers based on provided documents, with sources and evidence; it clearly states when the documents do not contain enough information.
- Repo: https://github.com/nhbl-ai/rag-study-buddy
- The repository was created as private; there has been no request to make it public.
- The user codes and builds the application themselves and chooses the documents and technologies. Help only with specific requests.
- `langchain-ai/rag-from-scratch` is an optional reference.
- The v0.1.0 terminal prototype loads LangChain documentation, preserves source URLs and chunk IDs, indexes chunks with `InMemoryVectorStore`, and delegates evidence analysis to a Deep Agents subagent. On branch `feat-chat-ui`, this logic is shared through `src/rag_study_buddy/rag.py`; `agent.py` remains the terminal entry point and `streamlit_app.py` adds a chat interface. Live indexing, retrieval, and generation for the original sample question were verified on 2026-10-08; this is not a comprehensive RAG quality evaluation.
