Xem cấu trúc notebook, trích nội dung hữu ích, giữ metadata nguồn và kiểm tra dữ liệu trước khi làm embedding. Không cần API key cho bước đọc và trích xuất notebook.

Chưa biết mức Python, thời gian học mỗi tuần, ngân sách API hoặc model người dùng muốn sử dụng. Chỉ hỏi khi thông tin đó cần cho bước tiếp theo.
